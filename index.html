House rules

What every tool here promises.

  1. Nothing you paste leaves your browser.

    The checks are plain JavaScript on the page. There is no backend to send anything to. You can read the source on GitHub.

  2. Every rule cites its source.

    Each check links the official documentation or the GitHub issue it comes from. If the documentation changes, the rule is wrong, and you can tell us.

  3. It says what it does not check.

    These are config linters, not live testers. They do not call your app or your provider, and each page says so.

  4. Free, no account, no tracking of content.

    We count visits and clicks with self-hosted Umami. We never store what you type.

  5. One problem per tool.

    Each tool exists because several people reported the same failure in the same words. We answer in those threads and keep the tool small.
