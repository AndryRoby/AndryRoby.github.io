    02 Ihre Daten

    Ein Lebenslauf ist ein sensibles Dokument. Deshalb verlässt er Ihren Browser nicht.

    • Es wird nichts gesendet

      Nach dem Laden kommuniziert diese Seite mit keinem Server. Sie hat keine Anmeldung, keine Datenbank und keine Besucherzählung. Das Foto liest eine Browserfunktion direkt von der Festplatte, kein Server.

    • Der Entwurf lebt im Browser

      Der begonnene Lebenslauf wird im lokalen Speicher (localStorage) dieses Browsers abgelegt, damit er beim Neuladen der Seite nicht verloren geht. Ein anderer Computer oder ein anderer Browser sieht ihn nicht.

    • Die Sicherung machen Sie selbst

      Wenn Sie die Browserdaten löschen, verschwindet der Entwurf mit ihnen. Deshalb gibt es die Schaltfläche In Datei speichern: Sie laden damit eine kleine JSON-Datei herunter, die Sie aufbewahren und jederzeit wieder einlesen können.

    03 Fragen

    Häufige Fragen

    Werden meine Daten irgendwohin an einen Server geschickt?

    Nein. Die Seite kann sie nirgendwohin schicken. Formular, Foto und der fertige Lebenslauf existieren nur im Arbeitsspeicher Ihres Browsers und in dessen lokalem Speicher. Nach dem Laden ruft die Seite außer dem eigenen Stylesheet und der Schrift von arling.sk keine weitere Adresse ab.

    Wie entsteht das PDF?

    Tlačidlom PDF herunterladen öffnet sich der Druckdialog Ihres Browsers. Wählen Sie dort als Ziel Als PDF speichern. Gedruckt wird nur das Blatt selbst im A4-Format mit 14 mm Rand, die Oberfläche des Werkzeugs landet nicht im Druck. Es wird keine Bibliothek zur PDF-Erzeugung geladen.

    Funktioniert das auf dem Handy?

    Ja. Auf schmalen Bildschirmen stehen die Schritte über dem Formular, die Vorschau öffnen Sie über eine Schaltfläche in der unteren Leiste. Das Drucken als PDF funktioniert auch im mobilen Browser, die Datei wird auf dem Handy gespeichert.

    Wie übertrage ich einen begonnenen Lebenslauf auf einen anderen Computer?

    Tlačidlom In Datei speichern laden Sie eine kleine JSON-Datei mit allen Daten und dem Foto herunter. Auf dem zweiten Computer öffnen Sie dieselbe Seite und laden die Datei über die Schaltfläche Aus Datei laden. Genauso können Sie sie sich selbst per E-Mail schicken.

    In welchen Sprachen kann das Werkzeug den Lebenslauf ausgeben?

    Slowakisch, Tschechisch, Deutsch und Englisch. Der Umschalter ändert die Abschnittstitel, die Monatsnamen, das Format des Geburtsdatums und die Bezeichnungen der Niveaus. Text, den Sie selbst geschrieben haben, wird nicht übersetzt, einen Übersetzer im Browser haben wir nicht.

    Was passiert mit dem Entwurf, wenn ich den Browserverlauf lösche?

    Der Entwurf verschwindet mit, denn er liegt im lokalen Speicher des Browsers. Dasselbe gilt für ein privates Fenster. Laden Sie deshalb nach jeder größeren Änderung eine Sicherung als Datei herunter.

    Was kostet es und brauche ich ein Konto?

    Nichts, und Sie brauchen keines. Keine Registrierung, keine E-Mail, keine Wasserzeichen im PDF. Das Werkzeug gehört zu einer Familie kleiner Werkzeuge auf arling.sk, die jeweils genau ein Problem lösen.
