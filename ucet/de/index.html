So funktioniert es

Kein Passwort, keine Registrierung.

Sie geben Ihre E-Mail-Adresse ein, bekommen einen 6-stelligen Code, tippen ihn hier ein oder klicken auf den Link direkt in der E-Mail. Die Anmeldung gilt 90 Tage auf diesem Gerät; melden Sie sich ab oder lassen Sie sich vergessen, gilt sie sofort überall nicht mehr.

Der Code gilt 15 Minuten und höchstens fünf Versuche, danach brauchen Sie einen neuen. Ein Passwort speichern wir nirgends, weil Sie keines haben: Es kann nichts durchsickern.

Käufe werden Ihrer E-Mail-Adresse auch dann zugeordnet, wenn Sie auf einem anderen Gerät bezahlt haben: Beim Anmelden fragen wir Stripe, was Sie mit dieser E-Mail-Adresse bei uns gekauft haben, und ergänzen es.

Warum ein Code und nicht nur ein Link in der E-Mail?

Ein Link aus der Post öffnet sich auf dem Handy oft in einem anderen Browser als dem, in dem Sie begonnen haben, sodass die Anmeldung dort nicht gelten würde, wo Sie sie brauchen. Einen Code können Sie überall eintippen. Der Link funktioniert trotzdem, nur als bequemere Abkürzung auf demselben Gerät.

Der Code ist nicht angekommen, was jetzt?

Prüfen Sie den Spam-Ordner und ob die E-Mail-Adresse richtig eingegeben wurde. Der Code gilt 15 Minuten; danach fordern Sie mit „Erneut senden" einen neuen an. Hilft das nicht, schreiben Sie an andrej@arling.sk.

Welche Daten speichern Sie über mich?

Ihre E-Mail-Adresse und die Liste Ihrer Käufe, Rechtsgrundlage ist die Vertragserfüllung. Käufe müssen wir nach dem slowakischen Buchhaltungsgesetz 10 Jahre aufbewahren, auch nach „Vergessen Sie mich"; der Anmeldecode selbst wird nach 15 Minuten gelöscht. Details in den Datenschutzbestimmungen.

Was genau macht „Vergessen Sie mich"?

Es löscht das E-Mail-Konto und den Fortschritt in allen Spielen bei uns. Käufe bleiben erhalten, das Gesetz erlaubt uns nicht, sie früher zu löschen. Spiele, die nur in Ihrem Browser ohne Anmeldung gespielt wurden, werden nicht gelöscht, die löschen Sie in den Browser-Einstellungen.

Funktioniert das auch ohne JavaScript oder im privaten Modus?

Die Anmeldung braucht JavaScript. Im privaten Modus funktioniert sie, meldet Sie aber beim Schließen des Fensters wieder ab, weil der private Modus den lokalen Speicher des Browsers löscht.
