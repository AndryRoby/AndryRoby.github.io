Schreiben Sie an andrej@arling.sk. Einen Fehler, den eines der Tools falsch verarbeitet hat, beheben wir bevorzugt; wenn Pro einfach nicht passt, erstatten wir die Zahlung innerhalb von 14 Tagen nach dem Kauf ohne weitere Fragen.

Was genau bekomme ich im Banktools-Paket?

Eine Pro-Lizenz, gültig in allen vier Tools gleichzeitig: SEPA pain.001 Doctor, SEPA-pain.001-Generator, camt.053 nach Excel und Zahlungsabgleich. Die kostenlose Version jedes einzelnen bleibt dauerhaft unbegrenzt. Pro fügt Komfort hinzu: gespeicherte Zahlerprofile, mehrere Dateien und Konten gleichzeitig, Mapping-Vorlagen für Pohoda, Omega (KROS) und Money S3, einen Verarbeitungsverlauf und bevorzugten E-Mail-Support.

Wie funktioniert eine Lizenz für vier Tools?

Nach der Zahlung wird ein signierter Lizenzschlüssel erzeugt und im Browser gespeichert. Alle vier Tools laufen auf derselben Domain arling.sk, sodass ein auf einer ihrer Seiten gespeicherter Schlüssel automatisch auch auf den anderen funktioniert. Falls das aus irgendeinem Grund nicht von selbst geschieht (anderer Browser, gelöschte Website-Daten), kann der Schlüssel jederzeit manuell im Abschnitt Lizenz oben oder direkt in einem der vier Tools eingefügt werden.

Werden meine Daten irgendwohin gesendet?

Diese Seite selbst verarbeitet keine Zahlungen oder Kontoauszüge, sie verwaltet nur die Lizenz. Die Verarbeitung von IBAN, Beträgen und Auszügen läuft in den einzelnen Tools vollständig in Ihrem Browser, nichts davon wird hochgeladen. Die einzige Netzwerkaktivität dieser Seite ist die Überprüfung des Lizenzschlüssels nach der Zahlung und ein anonymer Nutzungszähler über das selbst gehostete Umami.

Was, wenn ich nur eines der Tools möchte, nicht alle vier?

Jedes der vier Tools hat eine kostenlose Version ohne Limit bei Nutzung, Dateien oder Downloads, unabhängig von dieser Seite. Das Banktools-Paket lohnt sich, sobald Sie mindestens zwei davon wiederholt nutzen; reicht Ihnen die kostenlose Version für die gelegentliche Nutzung eines Tools, ist genau dafür sie gedacht, und Sie brauchen Pro nicht.

Wie bekomme ich eine Rechnung?

Stripe stellt die Rechnung aus und sendet sie sofort nach der Zahlung an Ihre E-Mail-Adresse. Bei diesem Verkauf tritt ARLing s. r. o. als Verkäufer über Stripe Managed Payments auf: Stripe übernimmt sowohl die MwSt. als auch die Ausstellung des Belegs direkt.

Sowohl das monatliche als auch das jährliche Abo können Sie jederzeit über den Link zur Zahlungsverwaltung kündigen, den Sie nach der Zahlung per E-Mail von Stripe erhalten; der nächste Zeitraum wird dann nicht mehr abgebucht.
