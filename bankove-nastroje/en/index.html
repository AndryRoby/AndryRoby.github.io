Questions people actually search for.

What exactly do I get in the Banking tools bundle?

One Pro licence valid across all four tools at once: SEPA pain.001 Doctor, SEPA pain.001 Generator, camt.053 to Excel and Payment matcher. The free version of each stays unlimited forever. Pro adds convenience: saved payer profiles, several files and accounts at once, mapping presets for Pohoda, Omega (KROS) and Money S3, a processing history, and priority email support.

How does one licence for four tools work?

After payment, one signed licence key is generated and stored in your browser. All four tools run on the same domain, arling.sk, so a key stored on one of their pages automatically works on the rest. If that does not happen by itself for some reason (a different browser, cleared site data), the key can always be pasted in manually in the Licence section above, or directly in any of the four tools.

Is my data sent anywhere?

This page itself does not process any payments or statements, it only manages the licence. Processing IBANs, amounts and statements runs entirely in your browser inside each tool; none of it is uploaded. The only network activity on this page is verifying the licence key after payment and an anonymous usage counter via self-hosted Umami.

What if I only want one of the tools, not all four?

Each of the four tools has a free version with no limit on uses, files or downloads, independent of this page. The Banking tools bundle pays off once you repeatedly use at least two of them; if the free version is enough for occasional use of one tool, that is exactly what it is for, and you do not need Pro.

How do I get an invoice?

Stripe issues and sends the invoice to your email right after payment. For this sale, ARLing s. r. o. sells through Stripe Managed Payments: Stripe handles both the VAT and issuing the document directly.
