01

About.

One sentence and four checkable numbers instead of adjectives.

ARLing s. r. o. is a one-person software company based in Bratislava that builds small tools for one exact problem: bank file checks, e-invoicing, GDPR documents and contract templates.

  • 11 daily logic games, each with a single solution that a program verifies at generation time, not a person after the fact.
  • 332 rule codes in the e-invoice check, covering EN 16931, Peppol BIS 3.0 and the German XRechnung.
  • 2,773 automated tests across the arling.sk tools (not counting the site itself), counted by the script ops/design/pocet-testov.mjs.
  • File tools (bank files, e-invoicing, GDPR documents, contract templates) process files in the browser; only what a payment needs reaches a server. The exception is the paid SEPA file check, where you upload the file to us. Proof, Renewals, Asistent and Stacklog run on a server.
