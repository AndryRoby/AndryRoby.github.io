E-invoice rule EN 16931

BR-O-05: Line 1 has VAT category O (not subject to VAT), so no VAT rate (cbc:Percent) may be given…

Example message from our sample invoice:

Line 1 has VAT category O (not subject to VAT), so no VAT rate (cbc:Percent) may be given there. Remove it.

Check my invoice Create an e-invoice

What the rule says

[BR-O-05]-An Invoice line (BG-25) where the VAT category code (BT-151) is "Not subject to VAT" shall not contain an Invoiced item VAT rate (BT-152).

Source of the quotation: EN 16931 schematron (ConnectingEurope/eInvoicing-EN16931, licence EUPL 1.2)

Business terms in the wording: BG-25, BT-151, BT-152

Why the validator reports it

The rule is part of the EN 16931 core. Our checker runs it on every UBL 2.1 invoice and credit note, in the EN 16931, Peppol BIS Billing 3.0 and XRechnung profiles.

Profile: EN 16931, Peppol BIS Billing 3.0, XRechnung 3.x

How we rate it: error

UBL elements: cbc:Percent

Where we point in the file: /Invoice/cac:InvoiceLine[1]/cac:Item/cac:ClassifiedTaxCategory/cbc:Percent

How to fix it

  1. Open the XML file and find the element cbc:Percent.
  2. Add or correct the value the way the wording of the rule above asks for.
  3. Save the file and check it again. The checker runs in your browser, the file is never uploaded.

A correct UBL 2.1 snippet

<cbc:Percent
    xmlns:cbc="urn:oasis:names:specification:ubl:schema:xsd:CommonBasicComponents-2">23.00</cbc:Percent>

The snippet is only the part of the document the rule is about, and the values in it are made up. Put it in the right place inside your invoice; the namespaces are written here only so that the snippet reads on its own.

Check the whole file

The checker runs 332 rules at once and shows the rule code, a plain sentence and the path to the element for every finding. The file is read in your browser and never uploaded. Free, no account.
