What the rule says

[BR-IC-07]-In a Document level charge (BG-21) where the Document level charge VAT category code (BT-102) is "Intra-community supply" the Document level charge VAT rate (BT-103) shall be 0 (zero).

Source of the quotation: EN 16931 schematron (ConnectingEurope/eInvoicing-EN16931, licence EUPL 1.2)

Business terms in the wording: BG-21, BT-102, BT-103

Why the validator reports it

The rule is part of the EN 16931 core. Our checker runs it on every UBL 2.1 invoice and credit note, in the EN 16931, Peppol BIS Billing 3.0 and XRechnung profiles.

Profile: EN 16931, Peppol BIS Billing 3.0, XRechnung 3.x

How we rate it: error

UBL elements: cbc:Percent

Where we point in the file: /Invoice/cac:AllowanceCharge[2]/cac:TaxCategory

How to fix it

  1. Open the XML file and find the element cac:TaxCategory/cbc:Percent.
  2. Add or correct the value the way the wording of the rule above asks for.
  3. Save the file and check it again. The checker runs in your browser, the file is never uploaded.

A correct UBL 2.1 snippet

<cac:TaxCategory
    xmlns:cac="urn:oasis:names:specification:ubl:schema:xsd:CommonAggregateComponents-2"
    xmlns:cbc="urn:oasis:names:specification:ubl:schema:xsd:CommonBasicComponents-2">
  <cbc:Percent>23.00</cbc:Percent>
</cac:TaxCategory>

The snippet is only the part of the document the rule is about, and the values in it are made up. Put it in the right place inside your invoice; the namespaces are written here only so that the snippet reads on its own.
