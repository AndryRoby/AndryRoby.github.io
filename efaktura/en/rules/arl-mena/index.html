E-invoice rule ARLing check

ARL-MENA: The element cbc:Amount carries the currency USD while the invoice is in EUR

The element cbc:Amount carries the currency USD while the invoice is in EUR. Check whether that is intended.

Check my invoice Create an e-invoice

What the rule says

This is our own check, not a rule from a schematron. That is why no external wording is quoted here.

Why the validator reports it

How we rate it: warning

UBL elements: cbc:Amount

Where we point in the file: /Invoice/cac:AllowanceCharge[1]/cbc:Amount

How to fix it

  1. Open the XML file and find the element cbc:Amount.
  2. Correct the value the way the message above describes.
  3. Save the file and check it again. The checker runs in your browser, the file is never uploaded.

A correct UBL 2.1 snippet

<cbc:Amount
    xmlns:cbc="urn:oasis:names:specification:ubl:schema:xsd:CommonBasicComponents-2" currencyID="EUR">100.00</cbc:Amount>

The snippet is only the part of the document the rule is about, and the values in it are made up. Put it in the right place inside your invoice; the namespaces are written here only so that the snippet reads on its own.
