BR-CL-16: Use a code from the UNTDID 4461 (for example 58 for a SEPA credit transfer) code list

Example message from our sample invoice:

Use a code from the UNTDID 4461 (for example 58 for a SEPA credit transfer) code list.

What the rule says

[BR-CL-16]-Payment means in an invoice MUST be coded using UNCL4461 code list

Source of the quotation: EN 16931 schematron (ConnectingEurope/eInvoicing-EN16931, licence EUPL 1.2)

Why the validator reports it

The rule is part of the EN 16931 core. Our checker runs it on every UBL 2.1 invoice and credit note, in the EN 16931, Peppol BIS Billing 3.0 and XRechnung profiles.

Profile: EN 16931, Peppol BIS Billing 3.0, XRechnung 3.x

How we rate it: error

Where we point in the file: /Invoice/cac:PaymentMeans/cbc:PaymentMeansCode

How to fix it

  1. Open the XML file and find the element cac:PaymentMeans/cbc:PaymentMeansCode.
  2. Add or correct the value the way the wording of the rule above asks for.
  3. Save the file and check it again. The checker runs in your browser, the file is never uploaded.

A correct UBL 2.1 snippet

<cac:PaymentMeans
    xmlns:cac="urn:oasis:names:specification:ubl:schema:xsd:CommonAggregateComponents-2"
    xmlns:cbc="urn:oasis:names:specification:ubl:schema:xsd:CommonBasicComponents-2">
  <cbc:PaymentMeansCode>58</cbc:PaymentMeansCode>
</cac:PaymentMeans>

The snippet is only the part of the document the rule is about, and the values in it are made up. Put it in the right place inside your invoice; the namespaces are written here only so that the snippet reads on its own.

Check the whole file

The checker holds 332 rules. For each file it runs the ones that match the invoice profile and shows the rule code, a plain sentence and the path to the element for every finding. The file is read in your browser and never uploaded. Free, no account.

What our tool does about this error

The checker finds BR-CL-16 in your file and shows where it sits in the XML. If you build the invoice in our generator, the finished XML runs through the same checker before the download and will not download while an error remains.

The checker and the preview cost 0 € and need no account. Downloading the finished XML costs 2.90 € excl. VAT, unlocked in the browser for 24 hours, or 9.90 € excl. VAT for 30 days including the CSV batch.
