PDF-Links auf dem E-Ink-Tablet prüfen

ARLing s. r. o. · 19. September 2026

Ein PDF kann ein Inhaltsverzeichnis enthalten, das Sie direkt zum gewünschten Tag oder Rätsel führt. Ein Link zur Lösung spart Blättern, ein Rücklink bringt Sie wieder zur Aufgabe. Damit Sie diese Navigation in Ihrem eigenen Ablauf nutzen können, sollten Sie zwei Dinge prüfen: Wohin führt der Link in der Datei, und wie öffnet Ihr Leseprogramm ihn? Ein gültiges Ziel im PDF sagt noch nicht, mit welcher Berührung Sie es auf einem bestimmten Tablet erreichen.

Beginnen Sie deshalb mit einer kleinen Probe. Öffnen Sie sie zunächst am Computer und folgen Sie dem Weg vom Inhaltsverzeichnis zur Zielseite und zurück. Übertragen Sie dieselbe Datei anschließend auf dem üblichen Weg auf Ihr Gerät und wiederholen Sie die Prüfung. So trennen Sie die Kontrolle der Datei von der Kontrolle Ihrer Bedienung. An Morning Quiet und Puzzle Post erklären wir, welche Werte wir messen, was diese Zahlen belegen und wo Ihre eigene Erfahrung mit dem Leseprogramm entscheidend bleibt.

Ein PDF-Link ist mehr als eine gedruckte Seitenzahl

Unsere internen Links sind eigene Annotationen im PDF. Sie entstehen aus den Verweisen der Satzvorlage beim Erzeugen der Datei. Der sichtbare Text gehört zur Seite; die Annotation bestimmt den aktiven Bereich und das Ziel. Ein Blick auf die Kapitelüberschriften im Inhaltsverzeichnis reicht deshalb nicht. Probieren Sie aus, ob Sie darüber tatsächlich die passende Stelle erreichen.

Bei der direkten Kontrolle von Morning Quiet fanden wir 592 interne Links im vollständigen Buch und 139 in der Probe. Keiner verwies auf eine Zielseite außerhalb der jeweiligen Datei. Das ist eine konkrete Aussage über die Navigation im PDF. Es ist kein Protokoll darüber, dass wir jeden Link auf jedem Tablet angetippt hätten.

Prüfen Sie den ganzen Weg, nicht nur den ersten Klick

Beginnen Sie in der Probe beim Inhaltsverzeichnis. Wählen Sie einen Tag oder eine Aufgabe, öffnen Sie das Ziel und suchen Sie den Rücklink. Wenn das PDF einen Verweis zur Lösung anbietet, folgen Sie auch diesem und gehen Sie anschließend zur Aufgabe zurück. So prüfen Sie einen kurzen Weg, den Sie beim Lesen oder Rätseln wiederholt benutzen werden.

Wiederholen Sie diesen Weg nach der Übertragung auf das Tablet. Verwenden Sie die Bedienung, die Ihr Gerät oder Ihre Anwendung für Links beschreibt. Wir geben keine einheitliche Geste für reMarkable, Kindle Scribe, Boox oder Supernote an: Diese physischen Geräte haben wir mit dieser Dateisammlung nicht getestet. Wie Lesen, Schreiben und das Öffnen eines Links zusammenwirken, müssen Sie im jeweiligen Leseprogramm ausprobieren.

Notieren Sie bei einem Problem den Dateinamen, das Programm und den Schritt, an dem Sie nicht weiterkommen. „Vom Inhaltsverzeichnis erreiche ich den Tag, finde aber nicht zurück“ ist genauer als „Das PDF funktioniert nicht“. Damit beschreiben Sie einen bestimmten Weg, statt vorschnell anzunehmen, dass überhaupt keine Links vorhanden sind.

Was die Zahlen aus unseren Dateien aussagen

Morning Quiet, Book 1 hat 214 Seiten; die kostenlose Probe für die ersten sieben Tage umfasst 52 Seiten. Die Zahlen 592 und 139 bezeichnen die Links in diesen beiden PDFs. Die Kontrolle fand weder externe Links noch interne Links zu einer Seite außerhalb der Datei. Buch und Probe sind englisch.

Die E-Ink-Ausgabe des ersten Puzzle Post hat 145 Seiten und 598 interne Links. Auch dort fand die direkte Prüfung keine Zielseite außerhalb der Datei. Wir können damit sagen, dass die geprüften Ziele existieren. Die Zielprüfung ersetzt jedoch weder das Lesen einer Seite noch einen Versuch, sie auf einem Display bequem zu bedienen.

Wenn wir Textfelder ergänzen, vermeiden wir außerdem, dass ein neues Feld einen Link überdeckt. Wir vergleichen die Linkzahl jeder Seite vor und nach der Änderung und prüfen die gerenderten Seiten bei 72 dpi. So können wir eine Veränderung bei diesem Verarbeitungsschritt erkennen. Die Bedienung in Ihrer Anwendung ist eine weitere, getrennte Prüfung.

Schreiben und Navigation getrennt ausprobieren

Ein funktionierender Link belegt noch kein funktionierendes Formularfeld. Der Link führt zu einem Ziel, das Feld nimmt Text auf und ein Anmerkungswerkzeug ergänzt einen eigenen Eintrag. Probieren Sie deshalb jede Funktion einzeln aus, die Sie später nutzen möchten.

Wenn Sie im PDF schreiben wollen, tragen Sie in ein bekanntes Feld eine kurze Antwort ein, speichern Sie Ihre Kopie und öffnen Sie sie erneut. Nutzen Sie Anmerkungen oder den Stift, prüfen Sie auch diese Einträge. Ein erfolgreiches Ergebnis beschreibt dann Ihren tatsächlichen Ablauf: eine bestimmte Datei, ein bestimmtes Programm und eine gespeicherte Kopie.

Eine Probe hilft dabei mehr als die Bezeichnung „interaktives PDF“ allein. Diese sagt noch nicht, welche Funktionen Sie benutzen werden oder ob Ihnen deren Bedienung zusagt. Der Weg über Inhaltsverzeichnis, Rücklink und einen eigenen Eintrag ist eine konkretere Prüfung.

Häufig gestellte Fragen

Funktioniert ein gültiger Link auf jedem Tablet?

Das lässt sich aus der Zielprüfung nicht ableiten. Sie belegt eine Eigenschaft der Datei; Unterstützung und Bedienung gehören zum Leseprogramm. Wir haben keine physischen Tests aller genannten Geräte durchgeführt. Probieren Sie die kostenlose Datei in Ihrem eigenen Ablauf aus.

Soll ich zuerst am Computer oder am Tablet testen?

Wir empfehlen zuerst den Computer und anschließend denselben Weg auf dem Tablet. Damit vergleichen Sie zwei Schritte Ihres Ablaufs. Daraus folgt nicht, dass jedes Programm am Computer sämtliche PDF-Funktionen unterstützt.

Muss ich für die Prüfung das vollständige Buch kaufen?

Morning Quiet bietet eine kostenlose Probe der ersten sieben Tage. Sie enthält 52 Seiten, 139 interne Links und 229 Textfelder. Damit können Sie Navigation und Texteingabe ausprobieren. Für den Download brauchen Sie weder Konto noch E-Mail-Adresse.

Probieren Sie die Datei auf Ihrem eigenen Gerät aus

Laden Sie die kostenlose Probe von Morning Quiet herunter und prüfen Sie Inhaltsverzeichnis, Rückweg und das Speichern einer Antwort. Buch, Probe und Angebotsseite sind englisch. Wenn Ihnen dieser Leseablauf zusagt, finden Sie auf derselben Seite das vollständige Buch.

Für Rätsel können Sie sich das englische Angebot von Puzzle Post ansehen. Wenn Sie lieber ausdrucken und keine Navigation auf dem Tablet benötigen, gibt es auch unsere Rätselbücher für Papier mit englischen Regeln.
