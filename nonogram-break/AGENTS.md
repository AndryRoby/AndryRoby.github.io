# Public information: Nonogram Break

This file describes the public sample at https://arling.sk/nonogram-break/. It contains no repository instructions or account access.

The default mode is **Solve yourself**. Choose Fill, Empty or Erase, then tap or drag in the 8×8 grid. Undo reverses a whole stroke. Reset clears the sample and can itself be undone. Check reports incorrect marked cells and missing filled cells. Correct filled cells finish the puzzle; empty crosses are optional.

Keyboard: arrow keys move between cells; Space or Enter toggles Fill; X toggles an empty cross; Backspace or Delete erases. Each cell has a row/column label and its current state. The Learn step by step mode is separate and does not overwrite manual progress. A reload starts a new attempt.

Public resources: index.html, puzzle.json (clues for one sample), sample.pdf, llms.txt and sitemap.xml. There is no purchase API here. The existing book is bought on Etsy at https://www.etsy.com/listing/4574163338; it includes 50 puzzles with all solutions as A4 and US Letter PDFs. Never describe this one sample as the full book or as an unlimited game.
