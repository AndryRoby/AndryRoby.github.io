Good to know

  • The video is about 17 seconds long, 1080 × 1920 (vertical) or 1920 × 1080 (horizontal), about 30 frames per second in Chrome and Edge.
  • Chrome and Edge save an MP4 file. Firefox saves a WebM file, which plays in Firefox, Chrome and VLC but can be less smooth; for an MP4 file, use Chrome or Edge.
  • We tested the editor in Chrome and Firefox on Windows; Edge runs on the same engine as Chrome. Safari on iPhone and Mac is not tested yet, and on iPhone and iPad every browser, Chrome included, uses Safari’s engine, so a computer with Chrome or Edge gives the most reliable result.
  • Keep this tab visible while the video is being made. It records in real time, so it takes about 20 seconds; if you switch to another tab, the editor stops and asks you to try again.
  • You can create as many versions as you like, for example one vertical and one horizontal, with and without music.
  • This is our own online editor, not a template for Canva or another app, and you need no account.
